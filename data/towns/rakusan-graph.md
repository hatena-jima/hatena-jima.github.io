# 離散グラフと行列

友だち関係や駅と線路の関係を図にするとき、人や駅を点、つながりを線で表すと分かりやすくなります。点を**頂点**、線を**辺**といい、この図を**離散グラフ**といいます。1つの頂点につながる辺の数を、その頂点の**次数**といいます。

数の表で表す方法もあります。数を長方形に並べたものを**行列**といいます。3つの頂点A、B、Cで、AとB、AとCがつながるなら、つながりを1、つながらないを0として次の表になります。

| | A | B | C |
|---|---|---|---|
| A | 0 | 1 | 1 |
| B | 1 | 0 | 0 |
| C | 1 | 0 | 0 |

例題です。4人A、B、C、DでAB、AC、BC、CDが友だちなら、辺は4本、次数はAが2、Bが2、Cが3、Dが1で、合計は8です。次数の合計は、辺の数のちょうど2倍になります。1本の辺が2つの頂点に数えられるからです。
