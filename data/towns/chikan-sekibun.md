# 置換積分法

(2x+1)³ のように、かたまりが入った式は、展開すると面倒です。かたまりを一つの文字に置き換えれば、知っている積分に戻せます。これが **置換積分法** です。

u=g(x) と置くと、du=g'(x)dx です。合成関数の微分の逆をたどっているわけです。例題 ∫(2x+1)³ dx では、u=2x+1 と置くと du=2dx、つまり dx=du/2 です。すると (1/2)∫u³ du = u⁴/8 + C = (2x+1)⁴/8 + C となります。

定積分では、積分する範囲も置き換えます。∫₀¹ 2x(x²+1) dx は、u=x²+1 と置くと du=2x dx、xが0から1までのときuは1から2までです。∫₁² u du = [u²/2] = 2-1/2 = 3/2 になります。最後にxへ戻す必要はありません。
