# 曲線で囲まれた面積

畑の形が曲がった線で囲まれていても、細い短冊に切って足し合わせれば面積が分かります。これが定積分の考え方です。区間 a≦x≦b で f(x)≧0 なら、曲線とx軸で囲まれた面積は ∫ₐᵇ f(x) dx です。

例題。y=sin x と x軸で、0≦x≦π の山の面積は ∫₀^π sin x dx = [-cos x] = 1+1 = 2 です。

二つの曲線の間では、「上の曲線の式 - 下の曲線の式」を積分します。f(x)が負になる部分があるときは、グラフの上下を調べて、どちらが上かを区間ごとに確かめます。

面積を求めるのに、置換積分法が必要なことも多いです。たとえば ∫₀¹ 2x e^(x²) dx は、u=x² と置くと ∫₀¹ eᵘ du = e-1 と簡単になります。次の町では、面積の考え方を広げて、立体の体積や曲線の長さを求めます。
