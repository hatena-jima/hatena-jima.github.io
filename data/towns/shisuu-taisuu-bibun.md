# 指数・対数関数の導関数

細菌が一定時間ごとに倍に増えるように、指数関数は増え方がだんだん大きくなります。微分すると自分自身にいちばん近い形になる底があり、それが **ネイピア数** e=2.718... です。e は (1+h) の 1/h 乗で h を0に近づけた極限の値で、このとき (eˣ)' = eˣ となり、微分しても形が変わりません。

対数関数では、log x を自然対数（底が e の対数）とすると (log x)' = 1/x（x>0）です。他の底の指数関数は、a=e^(log a) と見て、(aˣ)' = aˣ log a となります。

例題。y=x eˣ を積の微分で求めます。(x)'eˣ + x(eˣ)' = eˣ + x eˣ = (x+1)eˣ です。x=0 では傾きが1です。
